### 4. Correlation

Perhaps we want to investigate the relationship between the number of cigarettes smoked and the frequency of smoking.

The response variable (NUMCIGMO_EST) and the explanatory variable (USFREQMO) are both numerical. We use correlation to test this relationship.

```py
#test the relationship between number of cigarettes smoked and the frequency of smoking.

y = nesarc_data['NUMCIGMO_EST']
x = nesarc_data['USFREQMO']

x.corr(y)
```

The output shows a correlation of 0.53 which indicates that there isn't a strong relationship between these two variables. We could plot these variables using our scatter chart to visually see the results.

```py
seaborn.regplot(x="USFREQMO", y="NUMCIGMO_EST", fit_reg=True, data=nesarc_data)
plt.xlabel('Number of Cigs per month')
plt.ylabel('User frequency per month')
plt.title('Scatterplot for the Association between number of cigs and user frequency')

```

Don't forget to import in seaborn and matplotlib.pyplot

The scatter plot does not show any cluster of dots in a line so no strong relationship.
