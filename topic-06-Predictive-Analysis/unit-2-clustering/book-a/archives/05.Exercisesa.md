- Set the environment variable OMP_NUM_THREADS to 1

- Then load the data file gapmminder.csv into your data frame.

- Conduct the data management you think necessary prior to clustering on the following 5 variables.


~~~

INTERNETUSERATE
LIFEEXPECTANCY

- Then split the data into train and test sets.
- Run the cluster analysis using K-means for 1-9 clusters.
- Next plot the curve and determine how many is the fewest clusters that provides a low average distance.
- Further examine the number of clusters you consider appropriate based on the elbow curve.
- Create the scatter plot for the number of clusters you chose.
- Next using the model for the number of clusters you think is best, build a data frame with the custer assignemnt variable and the INCOMEPERPERSON variable, in the same way you did for GPA in the lab steps.
