### 3. ANOVA

To further investigate the relationship and not to rely only on the charts we created we do another test.

Remember the response variable is categorical (Y) and the independent variable is numerical (Age). 

- The null hypothesis is that no relaitonship exists between Age and survival.

- The alternate hypothesis is that a relationship exists between Age and survival. 

We use a one-way ANOVA test. It tests whether the means of two or more independent samples are significantly different, so if the p-value is small enough (<0.05) the null hypothesis of samples means equality can be rejected.


```py
#Test using ANOVA to see if the relationship is significant.

model = smf.ols('Y ~ AGE', data=dtf).fit()
print(model.summary())

#To make interpretation easy you can display the following:
table = sm.stats.anova_lm(model)
print(table)
p = table["PR(>F)"][0]
coeff, p = None, round(p, 3)
conclusion = "Correlated" if p < 0.05 else "Non-Correlated"
print("Anova F: the variables are", conclusion, "(p-value: "+str(p)+")")

```

The p value is less than .05  so we can reject the null hypothesis that no relationship exists and say that the passengers' age contributed to determining their survival. 

That makes sense as the lives of children were to be saved first in a life-threatening situation, typically abandoning ship, when survival resources such as lifeboats were limited

Again we want to validate the correlation between these two variables. They are both categorical so we use the chi-square test.

```py
#Test the correlation betwee the two categorical variables gender and survival.
#use chi-square to do this

cont_table = pd.crosstab(index=dtf[x], columns=dtf[y])
cont_table
scipy.stats.chi2_contingency(cont_table)

```
The first value (260.717) is the Chi-square value, followed by the p-value(1.1973e-58), then the degrees of freedom 1), and lastly it outputs the expected frequencies as an array. For the relationship to be significant the expected frequencies must be greater than 5, all of them are so the chi2 test results can be trusted.

We can reject the null hypothesis as the p-value is less than 0.05. Thus, the results indicate that there is a relationship between Gender and survival.
