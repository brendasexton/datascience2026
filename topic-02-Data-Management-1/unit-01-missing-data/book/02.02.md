### 2. Data Management

Data Management involves making decisions about data that helps to answer our research questions.

The code book and frequency distributions often are the first port of call for helping to make these decisions. You will use both of these tools often because they reveal things about the data that will be helpful to you. Those frequency distributions you did in lab 1 will be useful for every dataset you work on.

[nesarc codebook](./archives/NESARC_codebook.pdf)

There are several steps commonly considered when conducting your data management. In some cases the dataset is very clean and the variables are already well managed that you do not need to do much if any data management.

In all datasets you should consider each possible decision you make about a dataset. This means you play an active role in understanding your data and ensuring that you are asking your questions in an appropriate and meaningful way, as well as ensuring the changes you make are documented and justified.

### 2.1 Missing Data

A first step to consider is whether or not you need to code out missing data.

For example the adult smoker from step1. In the Nesarc codebook you can see the response of 1 in variable S3AQ3B1 is for daily smoking. The data will often include response categories that don't help you answer your question even though they provide information. For instance, in this variable we have a response category unknown, coded as a nine.

For these responses, we don't know how much these individuals smoked and therefore we may not want to include them in our analysis.

First we must ensure that the variable is a number. So we can use the following code to check the datatype. Again highlight and run just these lines of code.

```py
print(nesarc_data['S3AQ3B1'].dtypes)
```
If it is not a number then we must convert it.
```py
nesarc_data['S3AQ3B1'] = pandas.to_numeric(nesarc_data['S3AQ3B1'])

```
Then you can check to make sure it converted correctly by checking the data type again.

Next we are going to set any responses of 9 for variable S3AQ3B1 to missing so that Python disregards these values.

If you do a frequency count on that variable you will see how many 9 values there are:

```py
#counts for S3AQ3B1
print('counts for S3AQ3B1 - usual frequency when smoked cigarettes')
print(nesarc_data["S3AQ3B1"].value_counts(sort=True))

```
 You should see there are 3 values set to 9.

Then enter this code:

```py
nesarc_data['S3AQ3B1'].replace(to_replace=9,value=numpy.nan, inplace=True)
```

This replaces all the 9 values in that variable with NaN using the numpy library. Nan is how Python specifies missing data.

Remember when you use a variable you have to tell Python the data frame the variable is inside. So we have to include nesarc_data in the code.

Now we check to see if there are any values equal to 9 still remaining for that variable
```py
print((nesarc_data['S3AQ3B1']==9).sum())

```

This should result in 0.

Next we can count how many are Nan or null

```py
print(nesarc_data['S3AQ3B1'].isnull().sum())

```

or we do our frequency distribution again for that variable:

```py

print('counts for S3AQ3B1 - usual frequency when smoked cigarettes')
print(nesarc_data['S3AQ3B1'].value_counts(sort=True))


```

You should see that the 3 values that were originally 9 are now Nan.
