The covid data contains a date variable that is the date of observation. It is useful to be able to manipulate this date to help with your analysis.
So far in the NESARC data the date is already split into day, month year, allowing analysis for those categories.
In Python date types are available so that we can manipulate dates and times.
The link below is to the documentation on the datetime object.

- <https://docs.python.org/3/library/datetime.html#date-objects>

In step 3 using the addhealth_pds dataset you were introduced the use of lambda functions. To do the date separation for the covid data the following code uses lambda functions.

The syntax is lambda x: x
in our example x is the date variable in the covid_data
after the : is the function, in this case we are accessing the year attribute of the datetime object, and it is returned into the new variable called 'year'

```py
#divide the date object into three columns of year, month, and day data
covid_data['date'] = pandas.to_datetime(covid_data['date'])
covid_data["year"] = covid_data['date'].apply(lambda x:x.year)
covid_data["month"] = covid_data['date'].apply(lambda x:x.month)
covid_data["day"] = covid_data['date'].apply(lambda x:x.day)

```
