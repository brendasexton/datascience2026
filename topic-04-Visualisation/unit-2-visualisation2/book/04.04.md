#replace blanks with Nan

This is tedious and can lead to errors if we copy and paste and miss renaming something. We can in python write functions and conditions and loops the same as in all other programming languages. However as this module is not designed to teach you how to code in python the focus has been on understanding the steps needed to analyse data and visualise it.

However in this case there is a benefit to knowing how to shorten lines of code. Below I use a variable to hold an array of column names, then I loop through the array and replace spaces, then convert to numeric and then print out the describe stats.

```py
var_in_use = [ 'internetuserate', 'urbanrate', 'incomeperperson', 'hivrate']

for i in var_in_use:
    gapminder_data[i] = gapminder_data[i].replace(" ", numpy.NaN)
    gapminder_data[i] = pandas.to_numeric(gapminder_data[i])
    print('Descriptive stats for ' + i)
    print(gapminder_data[i].describe())
```

These 6 lines of code will completely replace the above 14 lines of code.
